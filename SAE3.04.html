SAE 3.04 - Mettre en place une infrastructure virtualisée

📋 Contexte du projet

  • Déploiement d'une infrastructure cloud complète sur OVH Public Cloud hébergeant une boutique en ligne PrestaShop et un portail administratif Odoo 16.
  • Le projet répond à des exigences strictes de haute disponibilité (SLA ≥ 99,9%) et de résilience avec gestion automatique de 3 pics de trafic annuels (Noël, Pâques, Saint-Valentin) nécessitant un scaling dynamique dès J-21.

☁️ Architecture Cloud OVH

  • Environnements - Production, Staging, Développement
  • Web/App PrestaShop - 2× instances (4 vCore, 8 Go RAM, SSD 100 Go)
  • App Odoo 16 - 2× instances (4 vCore, 8 Go RAM, SSD 100 Go)
  • Base de données - MariaDB Galera 3 nœuds (4 vCore, 16 Go RAM)
  • PostgreSQL - Master + Standby (4 vCore, 16 Go RAM)
  • OS - Ubuntu 22.04 LTS
  • Réseau - vRack isolé, IP statiques, Load Balancer OVH

🚀 Fonctionnalités et services

  • Load Balancing - Répartition automatique du trafic entre serveurs web
  • Haute disponibilité - Réplication Galera et PostgreSQL avec failover automatique
  • Auto-scaling - Ajustement dynamique des ressources selon la charge
  • Sauvegarde automatique - Snapshots et restauration point-in-time (RPO ≤ 1h)
  • Supervision 24/7 - Monitoring Grafana, alerting Alertmanager
  • Sécurité - Firewall OVH, isolation vRack, SSL/TLS
  • CI/CD - Tests en staging avant déploiement en production

🎯 Apprentissages critiques validés

Ce projet a permis de développer et valider les compétences suivantes du référentiel BUT R&T DevCloud :

  • AC24.01DevCloud - Proposer une solution Cloud adaptée à l'entreprise (analyse des besoins, choix OVH Public Cloud, dimensionnement des ressources pour SLA ≥ 99,9%)
  • AC24.02DevCloud - Virtualiser un environnement (déploiement d'instances Ubuntu 22.04 LTS, configuration des VMs PrestaShop et Odoo)
  • AC24.03DevCloud - Utiliser les services du Cloud (vRack, IP statiques, load-balancer OVH, snapshots, réplication des données)
  • AC24.04DevCloud - Analyser un service Cloud au travers des métriques (monitoring 24/7 avec Grafana, métriques CPU/RAM, alerting Alertmanager, auto-scaling)
  • AC25.02DevCloud - Mettre en production une application (déploiement PrestaShop et Odoo 16 avec environnements Prod/Staging/Dev, CI/CD)
