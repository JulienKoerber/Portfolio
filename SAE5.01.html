SAE 5.01 - Géolocalisation IoT via LoRaWAN

📋 Contexte du projet

Conception d'un système embarqué de géolocalisation de véhicule transmettant des données GNSS via LoRaWAN (The Things Network), avec optimisation de la consommation énergétique. Le système est autonome sur batterie, activé uniquement lors de détection de mouvement (accéléromètre), et permet le suivi en temps quasi-réel via interface web cartographique avec notifications SMS.

🔹 Fonctionnalités clés

  • Acquisition GNSS et transmission via LoRaWAN (The Things Network)
  • Optimisation payload - Coordonnées codées sur 3 octets
  • Visualisation web - Carte interactive avec Node-RED
  • Gestion énergétique - Modes sleep/deep sleep + activation par accéléromètre
  • Contrôle bidirectionnel - Arrêt à distance via downlink
  • Notifications - SMS lors de déplacement et commande de mise en veille

🔧 Architecture & Stack technique

  • Hardware - FiPy/LoPy + Pytrack (GNSS), Gateway LoRaWAN TTIG, Raspberry Pi, Clé 2G/3G
  • Embarqué - MicroPython sur Pycom avec gestion sleep/wake
  • Réseau - LoRaWAN via The Things Network (TTN) + MQTT
  • Backend - Node-RED sur Raspberry Pi (traitement données, cartographie, SMS)
  • Frontend - Interface web avec carte interactive (Leaflet/OpenStreetMap)
