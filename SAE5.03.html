SAE 5.03 - E-Commerce

Objectifs du Projet

    Concevoir et déployer une application e-commerce complète

  • Scalabilité : chaque microservice peut être dimensionné indépendamment selon la charge
  • Résilience : la défaillance d'un service n'entraîne pas l'arrêt global de l'application
  • Isolation :
    • Isolation fonctionnelle (un service = une responsabilité métier)
    • Isolation des données (une base de données par service)
  • Automatisation complète du déploiement et de la configuration

    • Fonctionnalités clés

    🔐 API Clients / Authentification

    • Inscription des utilisateurs
    • Connexion
    • Gestion du profil utilisateur
    Sécurité :
    • Authentification basée sur JWT (JSON Web Tokens)
    • Lors de la connexion, un token est généré
    • Ce token est requis pour accéder aux autres microservices, assurant une authentification centralisée et stateless
    Base de données :
    • Base PostgreSQL dédiée
    • Données utilisateurs totalement isolées des autres services
    Cette API sert de point d'entrée sécurité pour l'ensemble du système

    Architecture Globale

      L'application repose sur un cluster Kubernetes composé de 3 nœuds:
    • 1 noeud Master : orchestration et gestion du cluster
    • 2 noeuds worker : exécution des microservices applicatifs
      Chaque microservice est conteneurisé via Docker et déployé sous forme de pods Kubernetes, exposés par des Services.

    🎯 Apprentissages critiques validés

    • AC34.01 DevCloud – Concevoir, administrer et superviser une infrastructure Cloud ( mise en place et administration d’un cluster Kubernetes multi-nœuds sur machines virtuelles Debian)
    • AC34.02 DevCloud – Orchestrer les ressources Cloud (orchestration des microservices via Kubernetes avec Deployments, Services, ConfigMaps et Secrets)
    • AC35.02 DevCloud – Concevoir, gérer et sécuriser un environnement de microservices (architecture microservices sécurisée avec authentification JWT, isolation des bases de données et gestion sécurisée des configurations)
    • AC35.03 DevCloud – Gérer son infrastructure comme du code (automatisation complète de l’infrastructure avec Vagrant, Ansible et manifests Kubernetes versionnés)
