# 🌐 Portfolio Julien Koerber

> Portfolio web présentant mon parcours en BUT Réseaux & Télécommunications, spécialité Développement Cloud.

## 📖 Description

Site web interactif présentant mes compétences techniques, mes projets étudiants (SAE) et mon expérience de stage chez Merck KGaA.

**Fonctionnalités :**
- Design responsive moderne
- Onglets interactifs pour les compétences
- Showcase des projets avec cartes animées
- CVs téléchargeables (FR/EN)

## ️ Technologies

- **HTML5/CSS3** : Structure et design moderne
- **JavaScript** : Interactivité des onglets
- **Design** : Responsive, effets glassmorphism

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/JulienKoerber/Portfolio.git

# Naviguer dans le dossier
cd Portfolio

# Ouvrir dans le navigateur
open index.html
```
