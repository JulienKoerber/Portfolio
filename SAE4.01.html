SAE 4.01 - Développement d'une application bancaire

📋 Contexte du projet

    Conception et développement d'une application bancaire complète avec architecture distribuée et virtualisée, comprenant une interface client web, un système de validation automatique et un monitoring centralisé des logs.
    Le projet met en œuvre une architecture microservices avec Docker, permettant aux clients d'effectuer des opérations bancaires (dépôts, retraits, virements) validées automatiquement par un agent bancaire intelligent.

🏗️ Architecture distribuée

  • Interface Client Web - Application Django pour connexion/inscription et opérations bancaires
  • Agent Bancaire Automatique - Service de validation des transactions selon règles métier
  • Base de données PostgreSQL - Stockage des comptes, transactions et logs
  • Serveur NATS - Système de messagerie pour communication inter-services
  • Interface Administrateur - Dashboard de monitoring et consultation des logs
  • Conteneurisation Docker - Tous les services déployés via Docker Compose

⚙️ Fonctionnalités développées

👤 Partie Client

  • Authentification - Connexion et création de compte sécurisée
  • Opérations bancaires - Dépôts, retraits et virements entre comptes
  • Historique - Consultation des transactions validées et en attente
  • Interface responsive - Application web accessible depuis tous les appareils

🏦 Partie Agent Bancaire

  • Validation automatique - Vérification des conditions métier (solde, limites, conformité)
  • File d'attente - Gestion d'une table temporaire pour transactions en cours de traitement
  • Transfert automatique - Migration des transactions validées vers la table définitive
  • Nettoyage périodique - Suppression des transactions traitées de la file d'attente

📊 Gestion des Logs

  • Monitoring centralisé - Collecte de tous les événements système
  • Interface administrateur - Dashboard réservé aux superviseurs (/bank-admin/logs)
  • Filtres avancés - Tri par utilisateur, date, type d'opération
  • Traçabilité complète - Historique exhaustif pour audit et dépannage

🎯 Apprentissages critiques validés

Ce projet a permis de développer et valider les compétences suivantes du référentiel BUT R&T DevCloud :

  • AC24.02DevCloud - Virtualiser un environnement (conteneurisation complète avec Docker, orchestration multi-services via Docker Compose)
  • AC24.03DevCloud - Utiliser les services du Cloud (PostgreSQL conteneurisé, NATS message broker, services distribués)
  • AC24.04DevCloud - Analyser un service Cloud au travers des métriques (interface de logs, monitoring des transactions, traçabilité complète)
  • AC25.01DevCloud - Développer un microservice (agent bancaire autonome, API Django REST, services découplés communicant via NATS)
  • AC25.02DevCloud - Mettre en production une application (déploiement containerisé, gestion des dépendances, configuration multi-environnements)
