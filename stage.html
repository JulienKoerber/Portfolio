Stage chez Merck KGaA - 2ème année BUT R&T

🏢 Contexte du stage

  • Stage de 2ème année au sein du département R&D Bioprocédés de Merck KGaA, entreprise leader mondial dans les sciences de la vie et les technologies de laboratoire.
  • Mission principale : développer une solution de gestion centralisée des actifs informatiques et industriels (Asset Management) pour suivre l'ensemble des équipements connectés utilisés dans les processus de recherche et développement.

🎯 Missions réalisées

  • Analyse comparative - Étude de solutions de gestion d'actifs (avantages/inconvénients, coûts, scalabilité)
  • Proof of Concept (PoC) - Développement d'un prototype d'intégration automatique des devices dans Snipe-IT
  • Découverte automatique - Scan réseau et détection automatique des équipements industriels connectés
  • Développement Python - Script de collecte et transfert automatique des données vers la base Snipe-IT
  • Déploiement Edge - Implémentation sur Raspberry Pi pour fonctionnement en edge computing
  • Cybersécurité - Prise en compte des contraintes de sécurité (détection, collecte, transfert de données)
  • Fonctionnalités avancées - Étude de la mise à jour à distance des équipements via edge gateway

🔧 Technologies utilisées

  • Langage - Python (scripting, API REST, networking)
  • Plateforme - Snipe-IT (système de gestion d'actifs open-source)
  • Hardware - Raspberry Pi (edge gateway pour exécution décentralisée)
  • Protocoles réseau - ICMP, SNMP, Modbus TCP pour découverte et interrogation des devices
  • APIs - Intégration API REST Snipe-IT pour automatisation CRUD
  • Sécurité - Authentification, chiffrement, isolation réseau

💡 Compétences transversales développées

  • Développement Python avancé - Scripting réseau, manipulation d'APIs, threading
  • Intégration d'APIs REST - Authentification, requêtes HTTP, gestion des erreurs
  • Cybersécurité - Sécurisation des communications, protection des données sensibles
  • Edge Computing - Déploiement sur Raspberry Pi, optimisation des ressources
  • Gestion de projet - Méthodologie Agile, documentation technique, présentation
  • Environnement international - Collaboration avec équipes multiculturelles, anglais professionnel
  • Autonomie - Recherche de solutions, prise de décision, gestion du temps

  • Acquérir une vision industrielle des systèmes d'information et des objets connectés
  • Confirmer mon intérêt pour le DevOps, l'automatisation et le cloud computing
  • Renforcer mes compétences en cybersécurité dans un contexte industriel sensible
