SAE 3.01 - Prise WiFi connectée

📋 Contexte du projet

    Conception et développement d'une prise électrique intelligente connectée en WiFi, contrôlable à distance via une interface web et une application mobile Android.
    Le projet intègre des fonctionnalités domotiques avancées : contrôle à distance, programmation horaire, monitoring de température et notifications en temps réel via le protocole MQTT.

⚡ Fonctionnalités développées

  • Contrôle ON/OFF - Manuel (bouton physique) ou à distance (web/app)
  • Programmation horaire - Plages d'allumage/extinction automatiques
  • Monitoring en temps réel - Affichage de l'état via LED, interface web et application
  • Mesure de température - Capteur intégré avec alertes de dépassement
  • Sécurisation des communications - MQTT sur TLS avec authentification
  • Notifications push - Alertes sur changement d'état ou anomalie de température

🔧 Architecture technique

  • Microcontrôleur - ESP8266 avec module WiFi intégré
  • Protocole de communication - MQTT pour la messagerie temps réel
  • Broker MQTT - Serveur central de gestion des messages
  • Application Android - Interface mobile intuitive développée en Java/Kotlin
  • Interface Web - Dashboard de contrôle responsive
  • Capteur de température - DHT22 ou DS18B20

🎯 Apprentissages critiques validés

Ce projet a permis de développer et valider les compétences suivantes du référentiel BUT R&T :

  • AC22.01 - Déployer et caractériser des systèmes de transmissions complexes (ESP8266, MQTT, architecture IoT)
  • AC22.02 - Mettre en place un accès distant sécurisé (MQTT sur TLS, authentification, cryptage)
  • AC22.03 - Mettre en place une connexion multi-site via un réseau opérateur (architecture distribuée pour continuité de service)
  • AC22.04 - Déployer des réseaux d'accès des opérateurs (réseau WiFi avec gestion du roaming)
  • AC22.05 - Capacité à questionner un cahier des charges RT (analyse et justification des choix techniques)
  • AC23.02 - Développer une application à partir d'un cahier des charges donné, pour le Web ou les périphériques mobiles

💡 Compétences transversales développées

  • Développement mobile Android - Interface utilisateur intuitive et responsive
  • Protocoles IoT - Maîtrise de MQTT pour la communication temps réel
  • Électronique embarquée - Programmation ESP8266, gestion de capteurs
  • Sécurité des objets connectés - Chiffrement, authentification, protection des données
  • Architecture distribuée - Conception d'un système client-serveur-device
  • UX/UI Design - Création d'interfaces web et mobile ergonomiques
